Projeto Acadêmico IFPB Campus Sousa

Uma vitrine para explorar

Rota Motores é uma concessionária fictícia criada como projeto acadêmico da disciplina de Desenvolvimento de Aplicações Web, unindo catálogo moderno, ficha técnica e simulação de financiamento.

Fundamentação

Origem e Proposta

O projeto atende ao Tema 9 (Concessionária / Loja de Automóveis) da lista de temas práticos do IFPB Campus Sousa. Inspirando-se no método de levantamento orientado a negócios didáticos, o ecossistema foi estruturado para demonstrar fluxos de navegação reais, independência de páginas e armazenamento reativo.

A proposta de valor é integrar filtro de estoque, ficha individual por ID e simulação de financiamento em uma experiência suave com persistência de dados no navegador.

Arquitetura Técnica

Como esta aplicação funciona

1. Arquivos Estáticos

Páginas HTML independentes servidas a partir da pasta site/, preparadas para publicação estática contínua (GitHub para Render).

2. IndexedDB Nativo

Persistência local completa para veículos e uploads de fotos em Base64, preservando alterações após recarregar a aba ou fechar o navegador.

3. Design System Preciso

Identidade visual orientada ao estilo Apple com cantos suaves de 28px, botões pílula, zero sombras e paleta monocromática com azul elétrico.
